# Proyecto: Clasificador de Imágenes (Cuadrados, Círculos, Triángulos)

Este proyecto incluye:
- Generación de datos (imágenes de formas geométricas).
- Entrenamiento de una red neuronal para clasificarlas.
- Evaluación y almacenamiento del modelo.

## Estructura del Proyecto
- `env/`: Entorno virtual.
- `data/`: Imágenes generadas.
- `models/`: Modelo entrenado y pesos.
- `src/`: Código fuente.
